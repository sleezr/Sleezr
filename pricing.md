# Pricing — Sleezr

Last updated: 2026-08-22  
Currency: EUR  
Source of truth for checkout: https://www.sleezr.com/pricing

## Solo

- Price: €9.99 one-time (launch promo; list price €19.99)
- Limits: 1 device
- Features: Named environments, visual entries, apply + backups, DNS flush, import/export, multilingual UI (EN · FR · 中文 · 日本語), updates included
- Platforms: Windows · macOS · Linux

## Dual

- Price: €15.99 one-time
- Limits: 1 person, 2 devices
- Features: Same as Solo across two machines
- Note: 20% off vs buying Solo twice when you need a second device

## Team

- Price: from €29.99 per seat (launch promo; list price €49.99 per seat, 2+ seats)
- Limits: seats for the team; shared environment workflows
- Features: Solo capabilities plus team seat model for standardizing hosts setups
- Dashboard: https://www.sleezr.com/team

## What is included on paid plans

- Desktop app for Windows, macOS, and Linux
- Named environments (local, staging, prod, client, blocklist, custom, …)
- Automatic backup before apply + restore
- DNS flush tooling
- Lifetime updates for the purchased license tier (see site terms for details)

## What is not included

- Source code (Sleezr is not open source)
- Unlimited devices on Solo (use Dual or Team)
